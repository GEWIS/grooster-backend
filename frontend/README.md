# grooster-frontend

This directory contains the frontend of the roster maker of GEWIS. It is build using
the Vue framework in typescript.

It uses the API client from `../packages/grooster-client`, consumed via its published npm package `@gewis/grooster-backend-ts`.

## Project Setup

To make sure that you can use this frontend, make sure that you have the GO backend (`../backend`) running locally.

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```
